# grain-bids-to-excel v0.1.1 — BidBoard deployment release

## What changed

- Local Docker Compose deployment with Chromium included and persistent settings/spreadsheets.
- Better town/location discovery, scheduler and bid staleness handling.

## Install and upgrade

Stop BidBoard and back up app/data and Spreadsheets before upgrading. Existing Windows/Mac launchers remain supported; the deployment archive does not include their separately licensed embedded interpreters.

See [deployment instructions](../../DEPLOYMENT.md) and the attached checksums.
