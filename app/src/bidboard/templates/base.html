Quit {{ app_name }}?

How {{ app_name }} works

  1. Add your companies. Type each grain company's name - {{ app_name }} finds their website and their cash bids page, then shows you what it found before saving anything.
  2. Run a scan. One click. {{ app_name }} visits every company's bid pages, politely, and collects the numbers.
  3. Open your spreadsheet. A tidy Excel file lands in the Spreadsheets folder - ready to save, print, or forward.

If anything ever looks stuck, close the black RUN window and double-click RUN again. Nothing is ever lost.
