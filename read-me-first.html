BidBoard

Cash bids from every elevator, in one spreadsheet.

Getting started takes two clicks

1

Double-click SETUP - just once

This gets everything ready. It takes a few minutes and needs an internet connection. When it says SETUP COMPLETE, you're done with this step forever.

2

Double-click RUN - every time you want bids

BidBoard opens in your web browser automatically. Add the grain companies you care about, click Run a scan, and your spreadsheet lands in the Spreadsheets folder.

Good to know

If Windows shows a blue "Windows protected your PC" box: that's normal for a brand-new program. Click More info, then Run anyway. BidBoard is just a folder of ordinary files - it doesn't install anything into Windows.

Keep this whole folder together, wherever you like. Everything BidBoard needs lives inside it, and your spreadsheets always appear in the Spreadsheets folder right here.

If setup ever has trouble, there's a file called setup-log.txt right next to SETUP - send that to whoever set this up for you and they'll know exactly what happened.
